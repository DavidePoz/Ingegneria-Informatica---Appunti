# Ingegneria Informatica - Appunti (UniPD)

Qui sono pubblicati gli appunti di *alcuni* corsi della laurea triennale in ingegneria informatica presso l'università di Padova.
Sottolineo *alcuni* perchè ho un metodo di studio che varia molto in base al corso, per cui spesso mi capita di seguire le
lezioni senza prendere appunti. In compenso, quando decido di prendere appunti cerco di farlo con un livello di dettaglio
piuttosto alto, e spero che questo possa risultare d'aiuto per comprendere a fondo le materie.

In ogni caso, buona lettura e buono studio!

## OVERVIEW

Gli appunti dei primi due anni sono scritti in **Obsidian** (un'applicazione per gestire appunti in formato Markdown) e, 
per ogni corso, sono presenti sia la relativa cartella Obsidian con i file `.md` sorgente, che una cartella 
contenente le esportazioni in PDF.

Al terzo anno ho iniziato a prendere appunti in LaTeX nativo, ma sono comunque presenti sia i file sorgente
che l'esportazione in pdf.

> [!TIP]
> Potete modificare i file sorgente e usarli come *base per i vostri appunti*.
> Vi chiedo solo di **citare** me e/o questa repo se doveste ripubblicarli.
